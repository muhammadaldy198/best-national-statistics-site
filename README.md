NusaStat · Statistik Nusantara — a national statistics site for Indonesia: 24 indicators 2019–2025, 6 topic pages, 10 provinces compared, hand-rolled SVG charts, sortable tables with real CSV download, a purchasing-power calculator and a methodology page. Every figure carries its source and year (BPS, World Bank WDI, IMF WEO). Static files only — no network, no framework, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static server. `main.ts` hands the site in (copies `app/` + `screenshots/` to `/output` and writes `dossier.json` via the vendored make.fun library).
